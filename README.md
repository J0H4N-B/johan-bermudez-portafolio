# Portafolio de Johan Bermudez

Mi portafolio personal. Aquí cuento quién soy, dónde he trabajado y qué proyectos he hecho como desarrollador backend, para que quien me busque me conozca rápido y pueda escribirme.

Está en español y en inglés. El botón de idioma queda arriba a la derecha.

## Correrlo de manera local

```
npm install
npm run dev
```

## Generar una build

```
npm run build
```

Eso genera la carpeta `dist`. En Vercel importo el repositorio y lo publica solo.

## Cambiar textos

Los textos en español están en `index.html` y la traducción en `src/idiomas/en.json`.

## Hecho con

HTML, CSS, JavaScript, Vite, Bootstrap y Boxicons.
